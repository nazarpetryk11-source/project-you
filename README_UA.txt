PROJECT YOU — BUILD 0.1.0
Перший мобільний прототип PWA.

ЩО ВЖЕ ПРАЦЮЄ
- Профіль гравця, рівень і загальний XP.
- 7 характеристик із власним XP та рівнями.
- Щоденні стартові квести.
- Додавання власних квестів.
- Нагорода XP та GOLD за завершення квесту.
- Журнал подій.
- Збереження прогресу в пам'яті браузера (localStorage).
- PWA manifest і service worker для встановлення та базової офлайн-роботи.

ЯК ВІДКРИТИ НА ТЕЛЕФОНІ
1. Розпакуй ZIP у Acode або інший редактор/файловий менеджер.
2. Для першого тесту відкрий index.html у браузері або запусти локальний preview у редакторі.
3. Для встановлення PWA потрібен HTTPS-хостинг (наприклад GitHub Pages) або локальний сервер; просто відкритий file:// не дає повної PWA-інсталяції.
4. Після публікації відкрий сайт у Chrome → меню ⋮ → «Установити застосунок» / «Додати на головний екран».

ВАЖЛИВО
Це стартовий прототип, не фінальний APK. Прогрес зберігається локально в браузері цього пристрою. Після очищення даних браузера він може зникнути. Поки що немає AI, Health Connect, синхронізації між пристроями чи облікового запису.
Наступні етапи: покращити систему квестів/навичок, резервне копіювання, AI через захищений backend, автоматичні дані активності, потім Android APK-оболонка.
